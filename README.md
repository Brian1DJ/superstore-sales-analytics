# Superstore Sales & Profitability Analysis

An end-to-end retail analytics project using SQL, Excel, and Tableau
to analyze sales performance, profitability, customer segments,
products, regions, and shipping methods.

## Project Overview

This project explores a retail dataset to identify sales trends,
profitability patterns, and business performance across different
products, regions, and customer segments.

The analysis follows a practical workflow:

SQL → Excel → Tableau

## Business Questions

- Which categories and subcategories generate the most sales?
- Which categories and products generate the most profit?
- Which regions perform best?
- How do customer segments contribute to sales?
- How do discounts affect profitability?
- Which products have high sales but low profit?
- How do shipping methods relate to sales performance?

## Tools Used

- SQL / MySQL
- Microsoft Excel
- Tableau Public

## Project Workflow

1. Inspected and explored the dataset.
2. Cleaned and prepared the data.
3. Used SQL to query and analyze sales and profitability.
4. Used Excel for calculations, summaries, and validation.
5. Built an interactive Tableau dashboard.
6. Prepared insights and recommendations based on the analysis.

## Key KPIs

- Total Sales
- Total Profit
- Number of Orders
- Number of Customers
- Profit Margin
- Quantity Sold
